What the comparison shows

  • The UK issues framework's scoring (importance x impact, target ranges, resolution times) has no close international equivalent found so far.
  • Canada's approach is the closest peer to the DAM policy, but leaves scoring to departments.
  • European and UN frameworks judge statistical outputs (relevance, coherence, accessibility) rather than record-level rules; the ESS pack bridges the two.
  • Representativeness across groups appears in ISO/IEC 5259 for AI, but isn't a core dimension in the UK framework (finding F8).
  • Scotland, Wales and Northern Ireland use the Code of Practice for official statistics; the DAM policy is not mandatory there but can be adopted.

Framework and scenario packs

A pack turns a framework into requirements the toolkit can check. Most requirements are met automatically from your results; others need a person to confirm. Run one in Python with dqkit pack assess results.json --pack uk-dam-cda.

Convert results between frameworks

Results from the toolkit carry its dimensions, so they can be re-labelled for any mapped framework. In Python: dqkit crosswalk results.json --to iso-iec-25012. From an AI agent, use the crosswalk tool on the toolkit's MCP server. The AI assistant can do it in the browser.
