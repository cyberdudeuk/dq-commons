Set up the MCP server for an AI assistant, step by step

    
    
      
  1. Check your organisation allows the AI assistant you want to use, and that it can use local MCP servers.
    2. 
      
  2. Get the toolkit: download or clone the repository, then install it with pip install -r requirements.txt in that folder.
    3. 
      
  3. Add a local (standard input and output) MCP server to your assistant with the command python -m dqkit.mcp_server, started in the folder that holds the data you want it to read. Many assistants take a settings block like the one below.
    4. 
      
  4. Ask the assistant to list its tools. You should see the tools listed below.
    5. 
      
  5. Try: "Suggest starter rules for this CSV" or "Score this issue with the issues framework". Check the answers: the tools are deterministic, so the same input always gives the same result.
    6. 
    

    

    
The server is read-only, only reads files inside the folder it starts in (or DQKIT_MCP_ROOT), and makes no network calls.

    Comms and collaboration
    
  
    
    
    Share from any page
    Every page has Share this page under its title: copy the link to the page or the section you are reading, share with your device, by email, to Microsoft Teams or LinkedIn, copy embed code, or print.
    
    
    A tab in a Teams channel
    1. In the channel, select + to add a tab.
    2. Choose Website (if your organisation allows it).
    3. Paste the address of a Commons page, for example the playbook, and name the tab.
    
    
    A search shortcut in your browser
    1. In your browser's search engine settings, add a new site search.
    2. Use the address  with %s where the words go.
    3. Give it a short keyword, such as dq, then type dq and your words in the address bar.
    
    
    Updates in your channels
    Follow feed.xml in a feed reader or channel, or post releases automatically with a workflow (see the API examples).
    
    
    Intranet and wiki spaces
    Embed pages in SharePoint or Confluence spaces your teams already use, and link to sections from your own guidance so there is one source to maintain.
