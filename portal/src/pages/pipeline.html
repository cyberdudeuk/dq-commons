How the pipeline runs

A GitHub Actions workflow runs every Monday at 06:17 UTC, or when someone presses "Run workflow". The asset list lives in one portfolio file, portfolio.ndl.yaml; add a line to measure another asset.

1Test the kitStop if anything is broken, so wrong results are never published.
2MeasureRun each asset's rules when it is due; keep the history.
3ScoreIssues framework priority, trust level, route, ageing.
4SaveCommit results only when something really changed.
5EscalateOpen, update or close one GitHub issue per overdue problem.
6PublishRebuild this portal and publish it on GitHub Pages.

Status: the workflow has been checked by the kit's tests but has not yet run on GitHub, because the repository is not published yet. The same pipeline runs locally with python -m dqkit run portfolio.ndl.yaml. The runbook is docs/OPERATIONS.md.
