Write what good data looks like in plain English. The assistant turns each sentence into a rule, using fixed, published patterns, and the toolkit's engine checks the rules file before you see it. It runs entirely in your browser: no AI service, no account and nothing sent anywhere. You review everything before you use it.

How it works: each phrase it recognises (for example "valid NHS number", "not in the future", "one per person per month", "between 0 and 100", "one of A, B or C") maps to one check. Anything it doesn't recognise is listed, so you can add it by hand or ask the community. The patterns are in this page's source and in knowledge/, open for anyone to check or improve. The transparency record explains the change from an AI model to fixed rules.

Your data stays with you: a file you load is read in your browser and never uploaded. Don't type personal data into the box.
