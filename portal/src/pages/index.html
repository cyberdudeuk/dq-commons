Who could this miss?

  • Data that leaves out groups of people can pass every overall check. The kit's representativeness checks look for unknown values and for quality that differs between groups.
  • 45 of the 48 NDL pages that cover only part of the UK don't point to data for every other nation. People in Scotland, Wales and Northern Ireland are less well served.
  • 27 NDL pages offer no open, machine-readable format. That makes them harder to use with assistive technology.
  • Staff using assistive technology should be able to run checks and work the issue log. The tooling page asks suppliers about this.

What this is, and isn't

  • A working prototype built in the open: MIT-licensed code, OGL v3.0 content. It is not an official GDS product.
  • Every number here comes from the same automated run. The results date is in the top bar.
  • The weekly pipeline runs on GitHub once the repository is published. Until then it runs on demand.
  • Trust levels are suggestions for the data owner to confirm. They are not decisions.
