# Contributors

_Generated from `knowledge/build.yaml` by `scripts/gen_community_docs.py`._

We recognise every kind of contribution, not just code, following the all-contributors approach. Contributors are credited by GitHub username or organisation, never by personal details, and only if they agree.

## Kinds of contribution we recognise

| Kind | What it covers |
|---|---|
| code | Toolkit, portal and tests |
| content | Guidance, articles and frameworks |
| research | User research and evidence |
| design | Design, icons and accessibility |
| review | Reviewing pull requests and sources |
| ideas | Ideas, wishlist items and backlog |
| translation | Welsh and other languages |
| a11y | Accessibility testing |
| data | Rules, value sets and packs |
| community | Moderation and co-design |
