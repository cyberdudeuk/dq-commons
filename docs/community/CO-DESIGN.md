# Co-design sessions that work across time zones (BL-17, issue #17)

Partners range from the Pacific to the Caribbean, so a single 10am London session excludes many of them.
The planner on the [Help us build this](https://cyberdudeuk.github.io/dq-commons/build.html#codesign) page shows
three rotating slots in each partner's local time. The sessions themselves need facilitators and participants,
so the issue stays open until a full rotation has run and been reviewed.

## The rotation

| Slot | Time (UTC) | Works best for |
|---|---|---|
| A | 08:00 | UK, Crown Dependencies, Gibraltar, Africa, South Asia, Singapore (afternoon) |
| B | 15:00 | UK, Atlantic and Caribbean territories, Canada, the Falklands |
| C | 21:00 | Australia, New Zealand, Fiji (next morning); late evening in the UK, so UK attendance is optional |

Each topic runs in at least two slots, or one slot plus the asynchronous route, so nobody has to join outside their
working day. Slot C is led by a facilitator in the Asia-Pacific region where possible.

## Every session

- Materials sent 3 working days before, in accessible formats; captions on; recording only with consent.
- A written summary within 5 working days, and a 2-week asynchronous window to add comments.
- Decisions are recorded on the related GitHub issue, never only in the call.
- Sign up and ask for adjustments through the contact form ("Join co-design"). We never publish an email address.

## Measuring whether it works

After each rotation: attendance by region (totals only), how many people used the asynchronous route, and whether any
region has had no live slot in working hours. Report these in the weekly maintenance issue.
