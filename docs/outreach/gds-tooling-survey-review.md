# DRAFT, NOT SENT: feedback on the DQ tooling review, solutions survey and case study template

To: GDS Data Management Team (team inbox)
Status: draft for the project lead's approval. Do not send without approval.

Thank you for sharing the Data Quality Tooling Review, the Cross-Government Data Quality Solutions
Survey design and the case study template. They are a strong basis for evidence-led tooling
decisions. Some small changes before the survey launches would make the results far more useful,
because answers already collected can't be re-segmented later.

**Survey: before launch**
1. **Privacy notice.** Add one. Ask for name and email only when a respondent agrees to be contacted (Q108).
2. **Who is responding.** Add organisation type and headcount band. The review wants to compare usage by scale.
3. **Link to the DAM policy.** Ask how many CDAs each tool covers, which DQAP steps it supports, and whether it produces evidence for the CDA return.
4. **How widely tools are used.** Ask this; the review promises it, but no question covers it.
5. **Maturity scale.** Use the Data Maturity Assessment for Government levels (Beginning to Mastering).
6. **Rating directions.** Make them consistent. Q32 currently runs 1 = easy to 5 = hard.
7. **Tool list.** Add open-source and in-house options, plus accessibility, open-format export and exit questions.

**Tooling review**
- Add a short section on open-source and government-built tools. Smaller bodies with little or no budget currently see no affordable route.
- Add accessibility, open standards and exit as selection criteria (Technology Code of Practice).

**Case study template**
- Add before-and-after measures, the CDA identifier and an inclusion question.
- Align the stages with the Data Maturity Assessment.

**Shared Learning Library**
- Consider mirroring the library on GOV.UK or GitHub under OGL, so local government, devolved administrations and the NDL can find it.

**Decks**
- "EDSA" should read ESDA, or now CDA.
- The DQ Week deck's "DAM Policy Principles and Scope" slide reads as an organisation's internal policy rather than the cross-government policy.

**What we can offer:** an open-source (MIT) kit already does the following:
- analyses the survey export, with personal data removed
- drafts case studies in your template from measured results
- produces filled-in DQAP workbooks with issue ageing and escalation

Full review: `docs/SURVEY-REVIEW.md` and findings F10–F18 in `docs/GUIDANCE-CROSSWALK.md`.
