## Why two files

GitHub reads the root `LICENSE` file to label the repository's licence. It only recognises
that file when it holds the exact standard licence text. Keeping the OGL statement here means
GitHub, package indexes and code-search tools correctly show the code as MIT, while the
content licence stays clear and visible.
